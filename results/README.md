# Evaluation Results and Visualizations

This directory contains quantitative benchmark summaries, per-image test records, and enhanced image outputs from the official LOL `eval15` test set.

## Files
- `quantitative_summary.csv`: Master metrics across all 4 architectures trained under the uniform Stage 3 BF16 protocol.
- `eval15_per_image.csv`: Detailed image-by-image PSNR and SSIM scores across the 15 test scenes.
- `outputs_final/`: Directory containing predicted enhanced test images and JSON experiment logs.
- `graphs_final/`: Comparative training and validation curves.
